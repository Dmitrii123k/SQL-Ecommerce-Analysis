# SQL E-commerce Analysis

Портфолио-проект по анализу продаж интернет-магазина.
Для подготовки данных использовался Python (pandas), затем данные были загружены в PostgreSQL.

## Используемые технологии
- PostgreSQL
- DBeaver
- SQL
- Git
- VS Code
- Python (pandas)

## 📂 Структура проекта

### 📁 data

Исходные и подготовленные данные проекта.

- **raw/** — оригинальный датасет Online Retail.
- **processed/** — подготовленные данные после обработки Python.

---

### 📁 python

Python-скрипты для подготовки и загрузки данных в PostgreSQL.

- **01_prepare_data.py** — очистка и подготовка исходного файла.
- **02_load_data.py** — загрузка подготовленных данных в PostgreSQL.

---

### 📁 sql

Все SQL-скрипты проекта.

- **01_create_database.sql** — создание базы данных.
- **02_create_tables.sql** — создание таблиц.
- **03_data_quality.sql** — проверка качества данных (Data Quality Check).
- **04_data_cleaning.sql** — очистка данных и создание аналитического представления.
- **05_basic_analysis.sql** — базовые бизнес-метрики и обзор данных.
- **06_sales_analysis.sql** — анализ продаж по времени, выручки и сезонности.
- **07_cte.sql** — примеры использования Common Table Expressions (CTE).
- **08_rfm_analysis.sql** — RFM-анализ и сегментация клиентов.
- **09_views.sql** — создание представлений (VIEW) для аналитики.
- **10_final_queries.sql** — итоговые SQL-запросы проекта.
