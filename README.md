# SQL E-commerce Analysis

Проект по анализу данных интернет-магазина с использованием PostgreSQL и SQL. Для подготовки данных использовался Python (pandas), затем данные были загружены в PostgreSQL.
В проекте выполнены очистка данных, исследовательский анализ, RFM-сегментация клиентов и создание аналитических представлений (Views).

## Цели проекта

- Очистить исходный набор данных интернет-магазина.
- Выполнить анализ продаж и поведения клиентов.
- Провести RFM-анализ для сегментации клиентов.
- Закрепить навыки работы с SQL в PostgreSQL.
- Создать проект для портфолио Data Analyst.

## Датасет

В проекте используется открытый датасет **Online Retail**, содержащий транзакции интернет-магазина за период с декабря 2010 года по декабрь 2011 года.

Основные поля датасета:

- InvoiceNo — номер заказа;
- StockCode — код товара;
- Description — описание товара;
- Quantity — количество;
- InvoiceDate — дата и время покупки;
- UnitPrice — цена за единицу товара;
- CustomerID — идентификатор клиента;
- Country — страна клиента.

Перед анализом данные были очищены:

- удалены отмененные заказы;
- удалены записи с отрицательным количеством товаров;
- удалены записи без CustomerID.
